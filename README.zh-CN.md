# Vane 用例展示

[English](README.md) | **简体中文**

本仓库集中展示基于 [Vane](https://github.com/AstroVela/vane) 构建的可复现用例。
每个用例都会演示 Vane 如何在统一的 `Relation` 流水线中组合多模态数据与混合计算任务。

> 如果你想了解 Vane 项目本身，请访问
> [AstroVela/vane 仓库](https://github.com/AstroVela/vane)，查看源代码和项目文档。

## 用例

### AI / 数据流水线

* **[使用 Vane 构建可审计的多模态理赔分流流程](claims-disposition)** — 将
  PostgreSQL 中的理赔记录与 MinIO 中的照片、文档整合起来，通过有状态 OCR、
  多模态事实提取和确定性的 SQL 规则生成可审查的流程建议。**适合以下场景：**
  你需要一套端到端的理赔分流流程，并希望明确处理批准、拒绝、补充材料和人工审核等路径。

* **[使用 Vane 审计采购利益冲突与评分异常](procurement-compliance-audit)** —
  将供应商评分表与从图片中提取的推荐记录、评审会议证据进行核对，重新计算排名，
  并生成确定性的审计发现。**适合以下场景：**你需要结合文档证据与数值评分，
  发现可解释、可复核的合规风险信号。

* **[使用 Vane 构建理赔证据图谱](claims-evidence-graph)** — 将理赔照片、
  扫描文档和附件元数据规范化为可审计的证据表、验证报告及人工审核任务，
  并可选择使用 VLM 分析图片。**适合以下场景：**你需要的是可复用的理赔证据与
  数据质量层，而不是直接生成最终的流程建议。

* **[使用 Vane 发布多模态训练数据](multimodal-training-data)** — 在不同的类型化
  `Relation` 分支中处理文档、文本、图片和音频资产，然后发布通过验证的记录，
  同时保留可审查的拒绝记录和来源沿袭信息。**适合以下场景：**你正在整理多模态
  训练集或评测集，并需要可复现的质量门禁与发布清单。

* **[使用 Vane 治理企业 Agent 的证据上下文](enterprise-agent-evidence)** —
  将多模态资产与业务要求关联起来，识别缺失、冲突、过期或存在风险的证据，
  并生成经过治理的 Agent 上下文和有序审核队列。**适合以下场景：**企业 Agent
  在执行检索或模型推理之前，需要一个经过验证的上下文层。

* **[使用 Vane 对网页文本去重](web-text-deduplication)** — 使用 MinHash、
  LSH 候选生成、精确 Jaccard 验证和图聚类发现完全重复与近似重复的文档，
  再为每个聚类选择稳定的代表记录。**适合以下场景：**你需要清洗网页或文档语料库，
  同时希望保留候选诊断信息和可审查的重复文档聚类。

## 仓库规范

本仓库计划保持公开。演示代码、合成测试数据、文档和小型配置文件可以提交到 Git。
生成的输出、虚拟环境、模型权重、私有数据，以及因许可证限制而无法再分发的数据集，
不得提交到本仓库。
